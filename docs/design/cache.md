# 响应缓存

SHA-256 缓存键包含入口协议、stream、是否请求 usage、模型别名及规范化请求 JSON；规范化移除 user/metadata/stream/stream_options，再由独立维度补齐。默认仅 temperature=0 缓存；支持 bypass/force。16 分片 LRU，各自锁和字节预算；TTL 惰性失效并周期清扫。

仅成功完整响应、允许的 finish reason、最终精确计量及单条大小范围内才入缓存。流内异常、取消、配额截断不写入。每片可以淘汰最后一条；大于分片预算的记录不会突破总预算。键+响应体预算不含容器/allocator 元数据，不能直接等同 RSS。

命中回复原始响应体和 usage，上游尝试为 0，不产生模型消耗，记录 saved cost；缓存命中仍经过准入、限流和配额检查。模型别名路由按启动配置固定，不支持热加载。

三模型流式/非流式均验证 MISS→HIT，响应逐字节一致，命中约 1ms；小预算实际请求继续 MISS。release 固定真实响应缓存压测 347312.35 请求/秒、p99 3.19ms。TTL 与淘汰历史验收见 G13 记录。
