# API Key 管理

管理页位于 `/manage/`，无账号和登录，只管理页面创建的密钥。提供创建、一次性展示/复制、禁用、今日/累计 Token、日期范围汇总和请求明细；静态配置中的密钥继续有效，不出现在本页。

`web/management/` 保存原生 HTML/CSS/JavaScript，CMake 将资源嵌入网关，不依赖 Node 服务、外部 CDN 或运行目录中的静态文件。页面支持窄屏、空状态、错误提示和可见时轮询；所有名称以纯文本渲染，Token 使用十进制字符串传输及 BigInt 显示。

`management.enabled` 缺省 false；开启时必须配置 PostgreSQL，无需 Redis。可使用 [独立配置](../../home/management.json) 与 [启动脚本](../../deploy/run-management.sh)。新管理路由强制检查真实 loopback 对端和本机 Host；写入还要求同源 Origin、JSON、自定义请求头。旧 admin 访问开关不能放宽这些限制。

## 密钥与身份

`api_keys` 保存 UUID、展示名、SHA-256 摘要、末四位及创建/禁用状态。密钥由 OpenSSL 安全随机源生成 32 字节熵，只在创建响应中返回明文；没有明文恢复接口。数据库迁移 `002_api_keys.sql` 增加密钥表和请求二元分页索引。

`managed:<uuid>` 是动态密钥的稳定内部身份，复用原账本 key_name；展示名称不参与计量。静态用户名占用该命名空间会被拒绝。动态密钥禁用后不允许回退静态鉴权。

`KeyRegistry` 原子发布不可变快照；鉴权和在途会话持有主体共享所有权。禁用以快照发布为界，已经通过鉴权的请求继续结束并入账，后续请求返回 401。禁用不可恢复，历史用量保留。

## 数据库与回调

`KeyStore` 在 ledger loop 上使用独立 PG 控制连接，串行执行有界管理命令，连接设为 UTC、语句超时 5 秒。管理查询也使用这条连接，复用既有账本表和统计语义，不与旧 usage 读连接交错发送。这是对初始规格“复用账本读通道”的实现调整，用于隔离管理命令排队和连接会话设置。

创建/禁用先提交数据库，再重载并发布注册表，最后返回成功；重载失败时暂停动态准入并恢复数据库状态。没有将“提交成功但响应丢失”伪装成原子成功：页面提示刷新确认，遗失密钥可禁用后重新创建。

首次初始化、断线恢复均保证语句准备后再加载身份；连接不空闲时不开始恢复批次。普通只读 SQL 错误不会停用整个注册表，提交不确定或断线会暂停并重载。管理请求总数及存储队列均有界。

退出时先拒绝新增管理请求，并等待正常回调；即使触发强制退出，也会先在 ledger loop 关闭管理完成回调投递，再销毁 IO loops。注册表的延迟命令有生命周期标记，避免退出时访问已销毁对象。

## 用量与接口

新接口位于 `/api/manage/keys`：GET 列表、POST 创建、POST `/{id}/disable`、GET `/{id}/usage`、GET `/{id}/requests`。只返回公开 ID、脱敏信息和账本字段，完整凭据仅在创建成功时返回一次。

实际消耗使用账本 billable_tokens，包含各次上游尝试的已知消耗；网关响应缓存命中为 0。上游缓存 Token 属于输入的一部分，不再次相加。不完整上报显式提示，明细 null 显示“未上报”。页面数字只代表已提交账本，不包含进行中或尚未提交的请求。

日期按配置的计费时区计算，范围最长 366 天；累计使用完整日汇总。分页使用时间与 ID 的二元游标，校验游标日期、时间及筛选范围。UUID 在数据库中规范化，大小写不改变统计身份。
